# Bot Mayo đến từ bếp 💥

đây là bot thử nghiệm xài `sapphire framework` được viết trong typeScript

## Cách dùng

### 1) Các câu lệnh (bao gồm đang có và project chưa xong) 

```Mjob```

`sẽ cho bạn đi làm trong nhà hàng như ngoài đời thiệt 💥`

```
có 3 công việc khác nhau
- 【┆Bồi bàn
- 【┆Phục vụ
- 【┆Đầu bếp
```

```Mprofile```

```
hiển thị hồ sơ của bạn
Bao gồm:
• chức danh đầu bếp (đối với ai chọn nghề là đầu bếp) 
• nghề nghiệp hiện tại
•  level
chung chung là vậy
mỗi role sẽ có 1 mục nhiệm vụ hoặc item riêng
```

`sắp tới có thể làm thêm id`

```Mcook```

```
câu lệnh này dành cho công việc đầu bếp 
• (đang trong giai đoạn phát triển)
```

```Mserve```

```
câu lệnh này dành cho công việc bồi bàn/phục vụ
• (đang trong giai đoạn phát triển) 
```
