# Bot Mayo đến từ bếp 💥

đây là bot thử nghiệm xài [sapphire framework][sapphire] được viết trong typeScript

## Cách dùng

### Các câu lệnh (bao gồm đang có và project chưa xong) 

```Mjob```

sẽ cho bạn đi làm trong nhà hàng như ngoài đời thiệt 💥
có 3 công việc khác nhau
- 【┆Bồi bàn
- 【┆Phục vụ
- 【┆Đầu bếp
```

### Development

This example can be run with `tsc-watch` to watch the files and automatically restart your bot.

```sh
npm run watch:start
```

### Production

You can also run the bot with `npm dev`, this will first build your code and then run `node ./dist/index.js`. But this is not the recommended way to run a bot in production.
